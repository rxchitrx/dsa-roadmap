# Domain Context

## Purpose

This glossary defines the language used by the DSA Roadmap project. It describes the learner’s domain, not the implementation.

## Terms

### Topic

A broad DSA area, such as Arrays and Strings, Trees, Graphs, or Dynamic Programming.

### Concept

A specific DSA skill or pattern studied within a Topic, such as Sliding Window, BFS, or 0/1 Knapsack.

### Problem

A source-specific coding challenge that the learner studies and solves. Problems from different platforms remain separate by default.

### Attempt

One meaningful effort to solve a Problem, including the learner’s code, tests, result, and reflection.

### Review

A deliberate revisit of a previously attempted Problem to test independent recall and strengthen retention.

### Study Block

A planned unit of DSA work in the weekly routine.

### Work Session

The actual work performed against a Study Block, including time, outcome, and notes.

### Assessment

A timed set of Problems selected to test Concepts studied during a week.

### Learning Status

The learner’s retention state for a Problem or Concept. Passing a test does not automatically mean the material is learned.

### Fallback Problem

An Assessment Problem selected from older Concepts when the current week does not contain enough eligible Problems.
